## Сетка карточек каталога (`.container`)

| Ширина окна | Колонок | Строка CSS |
|-------------|---------|------------|
| **> 992px** | **3** | `.container { grid-template-columns: repeat(3, 1fr); gap: 24px; }` |
| **≤ 992px** | **2** | `@media (max-width: 992px)` |
| **≤ 640px** | **1** | `@media (max-width: 640px)` |
