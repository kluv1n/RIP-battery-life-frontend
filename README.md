# RIP — Battery Life (React)

Лабораторные 5–7: каталог типов аккумуляторов, заявка на расчёт времени работы, **Redux Toolkit**, **axios** (в т.ч. клиент в стиле codegen из Swagger), авторизация JWT.

## Как запустить

### 1. Бэкенд (обязательно для API, корзины и заявок)

Из каталога бэкенда курса (например `RIP2026-lab4_auth_swagger`):

```bash
cd /Users/kryzhnyiklim/RIP-frontend/RIP2026-lab4_auth_swagger
go run ./cmd/server
```

По умолчанию API слушает **порт `8080`** (как в `vite.config.ts` прокси).

### 2. Фронтенд

В отдельном терминале:

```bash
cd /Users/kryzhnyiklim/RIP-frontend/RIP-battery-life-frontend
npm install
npm run dev
```

Открой в браузере адрес, который выведет Vite (обычно **http://localhost:3000**).

- Запросы к API идут на **`/api/...`** — в режиме разработки **Vite проксирует** их на `http://localhost:8080` (см. `vite.config.ts`).
- При необходимости другой URL бэкенда задай переменную **`VITE_API_BASE_URL`** (например в файле `.env` в корне фронта: `VITE_API_BASE_URL=http://127.0.0.1:8080/api`).

### 3. Проверка без бэка

Каталог типов и часть страниц могут подставлять **mock**, если API недоступен; полный сценарий заявок и входа требует запущенного сервера и БД.

## Структура как в эталоне `new_front`

- **Navbar** — `BatteryAppHeader` (аналог `AppHeader`).
- **Хлебные крошки** — `BreadCrumbs` под шапкой, цепочка от «Главная» к текущей странице.
- **Корзина** в тулбаре каталога — `CartRow` в стиле эталона: текст «Типов в заявке: N», активная ссылка на черновик при `N > 0`.
- **Redux**: `src/store/` — пользователь и домен заявки (`batteryLifeApplication`).
- **Axios-клиент заявок**: `src/api/Api.ts` + `src/api/index.ts`.

## Полезные маршруты

| Путь | Назначение |
|------|------------|
| `/` | Каталог типов АКБ |
| `/battery/:id` | Карточка типа |
| `/battery-life/:id` | Заявка (черновик / просмотр) |
| `/battery-lives` | Список заявок (после входа) |
| `/signin`, `/signup` | Вход и регистрация |
| `/profile` | Личный кабинет (JWT для Postman) |
